# AgriSmart

Climate-smart agriculture web app with:
- Live weather insights
- Crop recommendations
- Crop problem solver
- Daily farm planner
- Admin data management

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query

## Local Setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Test
```bash
npm run test
```
